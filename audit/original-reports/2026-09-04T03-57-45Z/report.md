## Executive Summary

Critical infrastructure vulnerabilities are being actively exploited at scale, with CISA adding seven flaws to its Known Exploited Vulnerabilities catalog including a maximum-severity CVSS 10.0 vulnerability in SonicWall SMA 1000 appliances [CISA Adds Seven Exploited Flaws as Attackers Deploy Reverse Shells and Crypto Miners](https://thehackernews.com/2026/09/cisa-adds-seven-exploited-flaws-as.html). Simultaneously, a critical Cisco Nexus 9000 switch flaw (CVE-2026-20212, CVSS 9.8) allows unauthenticated remote code execution as root across ten Silicon One-based models with no workaround for affected IOS XR versions [Critical Cisco Nexus 9000 Flaw Lets Unauthenticated Remote Attackers Run Code as Root](https://thehackernews.com/2026/09/critical-cisco-nexus-9000-flaw-lets.html). These developments demand immediate patching prioritization and network segmentation review for any organization running affected network infrastructure.

Regulatory enforcement momentum continues to accelerate, evidenced by France's CNIL imposing a €500,000 fine on Hôpital privé de la Loire for inadequate protection of 727,000 patients' and relatives' data under GDPR [French hospital fined €500,000 after breach exposes data of 727,000](https://www.bleepingcomputer.com/news/security/french-hospital-fined-500-000-after-breach-exposes-data-of-727-000/). This penalty reinforces that data protection authorities are imposing substantial financial consequences for security failures affecting large-scale personal data processing, particularly in healthcare settings.

Supply chain and identity-based attack vectors are intensifying, with attackers compromising Coder's Cloudflare infrastructure to inject malicious Terraform modules containing credential-stealing code into the registry supply chain [Coder's registry infrastructure compromised to push malicious modules](https://www.bleepingcomputer.com/news/security/coders-registry-infrastructure-compromised-to-push-malicious-modules/). Concurrently, the "Phantom Deal" campaign demonstrates sophisticated social engineering targeting mid-level employees at large enterprises through fake merger and acquisition scenarios designed to authorize large financial transfers [Large Enterprises Targeted in Fake Merger & Acquisition Scams](https://www.darkreading.com/cyberattacks-data-breaches/large-enterprises-fake-merger-acquisition-scams). These trends indicate adversaries are increasingly exploiting trusted software delivery pipelines and human trust relationships rather than purely technical vulnerabilities.

Widely deployed application platforms face active exploitation, as a critical Elementor Pro vulnerability (CVE-2026-32475) is being weaponized to deploy webshells and execute arbitrary commands on WordPress servers [Critical Elementor Pro flaw exploited to take over WordPress sites](https://www.bleepingcomputer.com/news/security/critical-elementor-pro-flaw-exploited-to-take-over-wordpress-sites/). Additionally, an unauthenticated SQL injection in Sangoma Switchvox VoIP platforms (CVE-2026-9586) is being exploited to deploy reverse shells [Hackers exploit Sangoma Switchvox flaw to deploy reverse shells](https://www.bleepingcomputer.com/news/security/hackers-exploit-sangoma-switchvox-flaw-to-deploy-reverse-shells/), and HPE has patched a critical ArubaOS-CX remote code execution flaw [HPE patches critical ArubaOS-CX remote code execution flaw](https://www.bleepingcomputer.com/news/security/hpe-patches-critical-arubaos-cx-remote-code-execution-flaw/). The breadth of affected technologies—network infrastructure, CMS platforms, VoIP systems, and network operating systems—requires coordinated vulnerability management across diverse asset classes.
