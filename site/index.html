Key messages

  1. Active exploitation of critical vulnerabilities in widely deployed infrastructure components demands immediate vulnerability and access management review. OpenSSH configurations on musl libc systems are being targeted within hours of disclosure, a Barracuda email gateway flaw chain permits unauthenticated root access, and a SonicWall SSL-VPN MFA bypass is under active attack. Control owners must verify asset coverage, patch deployment, and authentication monitoring for these exposures. [1]; [3]; [7]

  2. Emerging data protection and governance risks from AI-assisted development and vendor data practices require strengthened secrets management and vendor oversight. Passwords and API keys are leaking into public GitHub repositories via Claude Code project settings, while security incident archives are being repurposed by vendors for model training without explicit enterprise consent. Data and risk owners should confirm repository scanning, secret revocation, and vendor contractual controls. [6]; [12]
