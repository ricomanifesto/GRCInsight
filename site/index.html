Key messages

  1. Critical authentication bypass and root privilege vulnerabilities in Citrix NetScaler, Check Point Security Gateways, and ConnectWise ScreenConnect are under active exploitation, demanding immediate patch deployment and supply chain assurance review. The Citrix NetScaler ADC flaw allows authentication bypass, while Check Point zero-day and PHP2Shell chains grant root access and deploy persistent backdoors. The ScreenConnect vulnerability enables worm-like lateral movement from MSP technicians to customer networks. Vulnerability and asset owners must confirm emergency patching across all affected assets, and supplier risk owners should validate MSP remediation status and monitoring coverage for lateral movement indicators. [1]; [2]; [6]; [9]

  2. Emerging AI agent permission models create uncontrolled data export paths when prompt injection redirects agent identities, while most organizations lack cryptographic inventories needed for post-quantum migration. AI agents with broad record access can exfiltrate data through malicious instructions, and incomplete cryptographic estates block quantum readiness planning. Identity and access owners should review agent permission scopes and implement session revocation, while risk and control owners must initiate cryptographic asset discovery and assign migration accountability. [3]; [12]
