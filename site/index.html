Key messages

  1. CISA added an actively exploited N-able MailAssure vulnerability to its Known Exploited Vulnerabilities catalog while two major service providers, Rackspace and Radware, disclosed breaches exposing customer Kubernetes clusters and cloud access keys respectively. These events demonstrate that vulnerability exploitation and supplier control failures are converging to create immediate remediation demands. Vulnerability and supplier risk owners must prioritize asset identification for the MailAssure flaw, verify Rackspace migration completion, and assess Radware credential exposure across their environments. [3]; [7]; [11]

  2. Broadcom patched a critical VMware vCenter authentication bypass following zero-day exploitation, a new extortion group launched large-scale vishing against single sign-on credentials, and an Iran-aligned actor deployed IPFS-based command infrastructure against telecommunications targets. These developments extend the threat surface across virtualization platforms, identity systems, and sector-specific espionage. Access management, vulnerability management, and monitoring owners should confirm patch deployment for VMware Directory Service, evaluate SSO phishing resistance, and assess IPFS traffic detection coverage. [1]; [9]; [12]
