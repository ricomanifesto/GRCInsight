Key messages

  1. Critical vulnerabilities in widely used infrastructure software are being actively exploited, with CISA adding a Perforce Puppet flaw to its Known Exploited Vulnerabilities catalog and threat actors exploiting an Apache Roller flaw for code execution. Simultaneously, a supply chain compromise of Microsoft's Agent Framework Python package on PyPI has exposed developer credentials. These developments require vulnerability and asset owners to confirm affected asset inventories and remediation status, and supplier risk owners to review dependencies and assurance evidence for compromised components. [2]

  2. Identity verification controls are under pressure from deepfake-enabled helpdesk impersonation and fake IT support requests that bypass authentication, while a physical attack can reset TPM lockouts to guess Windows Hello and BitLocker PINs. Additionally, the EggStreme malware toolkit has been rebuilt to evade detection against government targets. Access management and monitoring owners should verify authentication coverage, session revocation evidence, telemetry coverage, and detection test results to address these evolving threats. [8]
