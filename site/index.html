Key messages

  1. Critical vulnerabilities in widely deployed infrastructure products are under active exploitation, with CISA adding four flaws to its Known Exploited Vulnerabilities catalog while threat actors rapidly weaponized proof-of-concept code against Cisco Expressway and VMware vCenter. Control owners must prioritize asset identification and patching for the affected Apache Roller, Cisco Expressway, SAP NetWeaver, and VMware vCenter deployments, and verify that administrative access monitoring can detect authentication bypass attempts. [2]; [5]; [6]

  2. New attack vectors include a Linux KVM hypervisor flaw enabling cross-tenant memory access on AMD hosts, fraudulent ransomware recovery services indicted for wire fraud, and an agentic threat actor breaching Bell Canada's provisioning systems. Third-party risk owners should validate supplier security assurances for recovery services, while detection teams evaluate telemetry coverage for autonomous actor behaviors and virtualization escape indicators. [4]; [10]; [12]
