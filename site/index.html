Key messages

  1. Italy's €805 million fine against Meta for default-enabled gallery access without explicit consent demonstrates escalating GDPR enforcement on data processing defaults. Simultaneously, TSMC's confirmation that employee personal data was leaked through a cloud provider highlights third-party infrastructure as a direct path for sensitive data exposure. These developments require control owners to validate that default data access settings require documented consent and that cloud supplier contracts include enforceable breach notification and data protection obligations. [4]; [3]

  2. CISA's addition of the UnrealIRCd flaw to the Known Exploited Vulnerabilities catalog and PostgreSQL's patching of 52 flaws including a 22-year-old authenticated RCE vulnerability signal active exploitation of widely deployed infrastructure components. The Cursor marketplace compromise via a stolen Fireworks AI access key and the targeting of Check Point Security Gateways to deploy ESXi wipers demonstrate that supplier credentials and network security appliances are active attack vectors. Control owners must confirm emergency patching for KEV-listed vulnerabilities, extension rebuilding for PostgreSQL, least-privilege scoping of third-party access keys, and integrity monitoring for security gateway and hypervisor layers. [1]; [2]; [11]
