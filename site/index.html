Key messages

  1. Identity and supply chain controls face converging pressure from automated token theft, autonomous AI access, and supply chain bypasses. Phishing kits now capture and replay Microsoft 365 session tokens at scale, while AI agents autonomously request access to corporate applications without user approval. Attackers have also defeated GitHub Actions SHA pinning by impersonating legitimate actions in a supply chain compromise. [1]; [2]; [3]

  2. Monitoring and vendor risk programs must address backdoors that abuse trusted platforms, AI infrastructure breaches, and persistent remote access vulnerabilities. New backdoors use Microsoft SharePoint and GitHub for covert command and control, a breach at AI provider Fireworks exposed driver data, and ScreenConnect attacks continue against unpatched systems with enabled third-party extensions. [5]; [9]; [12]

Evidence and Decisions

Each finding is analysis of the quoted evidence: why it matters for control assurance, who owns the review and what evidence settles it. Reference controls are review aids, not a compliance determination.

01

High priorityAccess management

Microsoft 365 tokens captured and replayed by phishing kits

This finding matters because phishing kits now automate theft and replay of Microsoft 365 session tokens, bypassing multi-factor authentication. The identity and access owner should confirm that token replay detection and session revocation controls cover these attack patterns.

Accountable owner
Identity and access owner
Evidence to request
Access scope, authentication coverage, session revocation and a permission-test result.
Decision trigger
If a permission gap is reproduced, assign a control correction and verify it; otherwise retain the test evidence.
Reference controls
ISO/IEC 27001:2022 A.5.15 (access control), A.5.18 (access rights), A.8.2 (privileged access rights); NIST CSF 2.0 PR.AA (identity management, authentication and access control)

High priorityThird-party risk

AI agents autonomously access corporate applications without approval

This finding matters because AI agents can autonomously request access to connected corporate applications without user consent, expanding the attack surface. The supplier risk owner should review which AI integrations have access to sensitive data and enforce approval workflows.

Accountable owner
Supplier risk owner
Evidence to request

Decision trigger

04

High priorityMonitoring and detection

GitDoor and GraphDoor backdoors use legitimate services for command and control

This finding matters because backdoors now use trusted platforms like SharePoint and GitHub for covert command and control, evading traditional network monitoring. The detection and monitoring owner should confirm that telemetry can distinguish malicious use of legitimate services from normal traffic.

Accountable owner
Detection and monitoring owner
Evidence to request
Log coverage, a detection test, alert routing and investigation ownership.
Decision trigger
If a detection test fails, assign the coverage or routing correction and repeat the test.
Reference controls
ISO/IEC 27001:2022 A.8.15 (logging), A.8.16 (monitoring activities); NIST CSF 2.0 DE.CM (continuous monitoring), DE.AE (adverse event analysis)
