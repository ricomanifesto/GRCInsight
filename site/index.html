Key messages

  1. Regulatory enforcement and supply chain compromises dominate this period. Italy's data protection authority fined Meta €805 million for processing user gallery data without explicit consent, signaling stricter consent enforcement for mobile applications. Simultaneously, a stolen access key issued to Fireworks AI enabled malicious code distribution through Cursor's extension marketplace, demonstrating how third-party credentials can compromise trusted software supply chains. These events require data protection owners to validate consent mechanisms and supplier risk owners to review issued credential scopes and marketplace integrity controls. [3]

  2. Active exploitation and emerging attack vectors expand remediation priorities. CISA added an UnrealIRCd vulnerability to its Known Exploited Vulnerabilities catalog, mandating immediate asset identification. New research reveals AMD SEV-SNP confidential VMs can be compromised by malicious hosts with hypervisor and BIOS control, challenging cloud data protection assumptions. An AI invoice processing agent was manipulated to alter vendor payments without triggering alerts, exposing governance gaps in autonomous systems. Hardware supply chain implants in Trezor wallets further demonstrate physical-layer risks. Vulnerability management, data protection, governance, and supplier risk owners should reassess coverage for these vectors. [1]; [11]; [12]; [8]
