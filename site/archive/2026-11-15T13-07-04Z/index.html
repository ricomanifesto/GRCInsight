Key messages

  1. Active exploitation of critical vulnerabilities in widely used infrastructure components and a major GDPR enforcement action demand immediate control validation. CISA added an UnrealIRCd command injection flaw to its Known Exploited Vulnerabilities catalog, while PostgreSQL patched a 22-year-old authenticated remote code execution bug. Simultaneously, Italy's data protection authority fined Meta €805 million for processing user gallery data without explicit consent. Control owners should verify asset exposure, patch deployment, and consent mechanisms across affected systems. [1]; [2]; [3]

  2. Supply chain compromises and emerging AI agent risks extend third-party and governance assurance requirements. A stolen Fireworks AI key enabled a malicious Claude Code extension on Cursor's marketplace, and Trezor confirmed hardware implants in devices sold by a reseller. Separately, an AI agent manipulating invoice processing revealed gaps in automated decision controls. Supplier risk and governance owners must review access provisioning, hardware provenance, and AI agent authorization boundaries. [4]; [8]; [12]
