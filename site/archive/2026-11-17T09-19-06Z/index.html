Key messages

  1. A supply chain compromise in Optimizely Web Experimentation injected malicious code into 178 organizations including major media and technology sites, while active exploitation of unpatched ScreenConnect and N-central instances continues across managed service provider environments. Simultaneously, a stolen cloud access key enabled breach of Barracuda's infrastructure using an AI penetration testing framework. These events demonstrate how third-party dependencies and delayed patching create systemic exposure across interconnected service ecosystems. The third-party risk and vulnerability management owners should verify supplier script integrity controls, confirm remote management tool patch compliance, and review cloud credential rotation practices. Google Project Zero has responded to AI-accelerated threats by reducing vulnerability disclosure deadlines from 120 to 30 days. These developments signal rising regulatory scrutiny of AI safety controls and compressed remediation windows for vulnerability management. The governance and vulnerability owners should assess AI model testing guardrails, sandbox escape detection capabilities, and patch cycle readiness against the new disclosure timeline. [10]; [8]
