Key messages

  1. Critical vulnerabilities in widely used libraries and managed service provider tools are being actively exploited, requiring immediate asset identification and patching across software supply chains. The binary-parser library flaw allows arbitrary code execution, while ScreenConnect and ASP.NET anti-CSRF library vulnerabilities enable remote compromise of technician endpoints and legacy applications. Microsoft Azure API Management Classic tiers have also been exploited to steal API credentials targeting energy sector organizations. Control owners must verify affected versions, apply patches, and review supplier dependencies for these components. [1]; [2]; [4]; [10]

  2. Data breaches at critical infrastructure providers and exposed operational technology devices highlight gaps in data protection and authentication controls. Korea Electric Power Corporation confirmed a breach affecting 1.5 million individuals, and industrial serial gateways broadcast their authentication status with many lacking protection. These incidents underscore the need for robust data handling controls and OT device hardening. [7]; [5]
