Key messages

  1. Multiple critical vulnerabilities have been disclosed in widely used software libraries and third-party remote management tools, including a code injection flaw in a popular binary parser, an exploited ScreenConnect flaw targeting managed service providers, an SSRF vulnerability in an email filtering service, and an actively exploited legacy anti-CSRF library. These findings increase supply chain risk and require urgent verification of asset inventories and supplier patching. [1]; [2]; [3]; [4]

  2. A data breach at a national power utility exposed personal information of customers, employees, and contractors, while a vulnerability in Azure API Management Classic tiers was exploited to steal API credentials linked to attacks on energy companies. These incidents highlight gaps in data protection and privileged access controls for critical infrastructure and cloud services. [7]; [10]
