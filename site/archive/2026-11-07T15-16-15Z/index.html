Key messages

  1. Active exploitation of authentication bypass flaws in OpenSSH on musl C library, Barracuda Email Security Gateway, and SonicWall SSL-VPN allows unauthenticated root access and MFA circumvention, directly undermining access controls across critical infrastructure. Control owners must verify that patches are deployed on all affected appliances, that privileged session monitoring covers these vectors, and that no unauthorized administrative access has occurred. [1]; [3]; [6]

  2. The Microsoft Paint fix delivered only via the Microsoft Store, the exposure of credentials through Claude Code project settings files committed to public repositories, and active exploitation of the Plex2Shell vulnerability chain on QNAP NAS devices highlight gaps in patch management, secrets handling, and third-party software update processes. Owners should confirm Store update deployment, scan for exposed secrets in version control, and ensure Plex Media Server is updated via the QNAP App Center. [2]; [5]; [12]
