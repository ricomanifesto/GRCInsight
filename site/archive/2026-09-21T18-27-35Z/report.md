## Executive Summary

Critical infrastructure and identity management platforms are under active exploitation, with multiple maximum-severity vulnerabilities disclosed in September 2026. Cisco Identity Services Engine (CVE-2026-76460) and Microsoft Azure AI Foundry (CVE-2026-85889) each received a CVSS 10.0 rating, while Orkes Conductor (CVE-2026-58138) and a Linux kernel flaw (CVE-2025-39682) carry scores of 9.8 and are confirmed exploited in the wild per CISA [CISA Flags Three Linux Kernel Vulnerabilities Exploited in the Wild](https://thehackernews.com/2026/09/cisa-flags-three-linux-kernel.html). SolarWinds Access Rights Manager (CVE-2026-28326) adds a high-severity 8.8 vulnerability affecting all versions through 2026.2 [SolarWinds Patches ARM Hard-Coded Key Flaw Enabling Unauthenticated RCE](https://thehackernews.com/2026/09/solarwinds-patches-arm-hard-coded-key.html). These findings demand immediate patching prioritization and compensating controls for identity, AI, and workflow automation platforms. **Evidence:** [Critical Pre-Auth RCE in Orkes Conductor Workflow Platform Exploited in the Wild](https://thehackernews.com/2026/09/critical-pre-auth-rce-in-orkes.html); [Cisco Zero-Day Highlights API Endpoint Authentication Issues](https://www.darkreading.com/vulnerabilities-threats/cisco-zero-day-api-endpoint-authentication-issues); [Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation](https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html)

Supply chain and developer-targeted attacks have evolved beyond traditional installation-time defenses. A malicious npm package campaign demonstrates runtime behavior obfuscation that evades install-script scanning [Malicious npm packages evade install-script defenses at runtime](https://www.bleepingcomputer.com/news/security/malicious-npm-packages-evade-install-script-defenses-at-runtime/), while North Korean actor Jade Sleet compromised an India-based IT services provider using FLATROOF and ROOFDECK backdoors to pivot into downstream networks [Jade Sleet Linked to Indian IT Provider Breach With FLATROOF and ROOFDECK Backdoors](https://thehackernews.com/2026/09/jade-sleet-linked-to-indian-it-provider.html). ClickFix social engineering lures now deliver the previously undocumented ChainScript RAT, masquerading as legitimate SaaS applications including Spotify, Zoom Workplace, and Microsoft Teams [ClickFix Lures Deploy ChainScript RAT Using Polygon to Rotate C2 Infrastructure](https://thehackernews.com/2026/09/clickfix-lures-deploy-chainscript-rat.html). These campaigns indicate a strategic shift toward persistent, evasive compromise of software development and delivery pipelines.

AI-assisted attack chains and sandbox escapes represent an emerging class of risk to generative AI infrastructure. Researchers demonstrated escape from OpenAI's Codex sandbox to execute commands on host systems [Researchers escape OpenAI Codex sandbox to run commands on host](https://www.bleepingcomputer.com/news/security/researchers-escape-openai-codex-sandbox-to-run-commands-on-host/), while a separate chain leveraged Anthropic's Claude Opus 5 to compromise OpenAI employee accounts and access internal code repositories [Claude Opus 5 Helped Researchers Take Over OpenAI Staff Accounts via Chained Flaws](https://thehackernews.com/2026/09/claude-opus-5-helped-researchers-take.html). The BragJack proof-of-concept further shows that a single malicious browser extension can hijack AI assistants across Chrome, Edge, Opera Neon, Perplexity Comet, and Claude in Chrome via a Prompt Forcing technique [BragJack attacks hijack AI browser agents through malicious extensions](https://www.bleepingcomputer.com/news/security/bragjack-attacks-hijack-ai-browser-agents-through-malicious-extensions/). These incidents collectively signal that AI tooling and browser-integrated agents are becoming viable attack surfaces requiring dedicated governance.

Operational resilience is affected by defensive updates themselves. Microsoft's September 2026 security updates inadvertently broke the Windows File History backup feature on some systems, illustrating the continuity risk of patch deployment without validated rollback procedures [Microsoft: September updates break File History backup feature](https://www.bleepingcomputer.com/news/microsoft/microsoft-september-updates-break-file-history-backup-feature/). Organizations must balance emergency patching of actively exploited vulnerabilities against the potential for update-induced service disruption, particularly for backup and recovery capabilities that underpin ransomware resilience.
