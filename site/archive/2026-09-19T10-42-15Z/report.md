Three critical vulnerabilities with maximum CVSS scores of 10.0 emerged in September 2026 across core enterprise infrastructure: Cisco Identity Services Engine (CVE-2026-76460) [Cisco Zero-Day Highlights API Endpoint Authentication Issues](https://www.darkreading.com/vulnerabilities-threats/cisco-zero-day-api-endpoint-authentication-issues), Microsoft Azure AI Foundry (CVE-2026-85889) [Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation](https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html), and Docker Sandboxes on macOS (CVE-2026-77179) [Critical Docker Sandboxes Flaw Lets Malicious Guest Code Read and Modify macOS Host Files](https://thehackernews.com/2026/09/critical-docker-sandboxes-flaw-lets.html). OAuth consent abuse remains a viable attack path that MFA cannot mitigate, requiring least-privilege scopes, consent monitoring, and rapid revocation capabilities [MFA Won't Save You From OAuth Consent Abuse](https://www.darkreading.com/vulnerabilities-threats/mfa-oauth-consent-abuse). WordPress administrators face a new attack chain (Click2Shell) enabling forced theme installation and potential code execution via crafted links [New WordPress Click2Shell Flaw Forces Theme Installs, Can Chain to Code Execution](https://thehackernews.com/2026/09/new-wordpress-click2shell-flaw-forces.html).
