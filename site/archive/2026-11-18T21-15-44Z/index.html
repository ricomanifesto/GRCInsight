Key messages

  1. Critical vulnerabilities in foundational infrastructure components are under active exploitation, requiring immediate vulnerability management review. CISA has added a Perforce Puppet flaw to its Known Exploited Vulnerabilities catalog, a decade-old NGINX HTTP/2 flaw enables unauthenticated code execution, and a Java runtime vulnerability affects Jira, Jenkins, and Keycloak. These exposures weaken assurance across web servers, automation platforms, and enterprise applications. Vulnerability owners must confirm affected assets are identified and remediation or compensating controls are validated. [4]; [1]; [3]

Microsoft's official Agent Framework PyPI package was compromised to steal cloud credentials, a Wellington IT breach exposed data from 50 credit unions, and attackers are using deepfakes with helpdesk impersonation to bypass identity verification. These events weaken supplier assurance and identity control effectiveness. Supplier risk and identity owners should review dependency verification, supplier access scope, and verification control resilience. [10]; [8]; [12]
