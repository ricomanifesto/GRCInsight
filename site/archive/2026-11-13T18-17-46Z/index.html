Key messages

  1. Critical vulnerabilities in PostgreSQL databases and AMD SEV-SNP virtual machines, alongside hardware implants in Trezor cryptocurrency wallets, expose systemic weaknesses in vulnerability management, data protection, and third-party risk controls. The PostgreSQL flaw allows authenticated remote code execution requiring extension rebuilds, the AMD attacks enable hypervisor-level memory access, and the Trezor implants demonstrate supply chain compromise of cryptographic devices. Control owners should prioritize patching PostgreSQL, assessing cloud isolation guarantees, and verifying hardware procurement integrity. [1]; [4]; [7]

  2. Operational disruptions to German military drones and Microsoft printing functions, combined with AI agent manipulation enabling unauthorized financial changes, highlight gaps in incident response, change management, and governance over automated systems. The drone cyberattack by hostile actors, the security update regression, and the AI agent's susceptibility to prompt injection each reveal insufficient containment, validation, and oversight controls. Owners should review incident procedures for operational technology, change validation for security patches, and AI agent permission boundaries. [2]; [5]; [9]

AMD SEV-SNP-protected virtual machines expose memory to malicious host

These attacks undermine the confidentiality and integrity guarantees of hardware-isolated virtual machines, affecting data protection assurances in multi-tenant clouds. The data and privacy owner should assess whether cloud provider controls mitigate hypervisor-level compromise.
