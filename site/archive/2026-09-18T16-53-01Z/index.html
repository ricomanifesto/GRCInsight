Executive Summary

Critical infrastructure vulnerabilities discovered in September 2026 demand immediate board attention. A maximum-severity flaw in Azure AI Foundry (CVE-2026-85889) enables unauthorized privilege escalation without customer action required, while a critical Docker Sandboxes escape (CVE-2026-77179) on macOS allows malicious guest code to read and modify host files. The Unbound DNSSEC validator heap overflow (CVE-2026-81642) permits remote code execution via malicious DNS zones. Source: Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation, Critical Docker Sandboxes Flaw Lets Malicious Guest Code Read and Modify macOS Host Files, Critical Unbound DNSSEC Validator Flaw Could Allow RCE via a Malicious DNS Zone

Supply chain and identity-based threats are escalating in sophistication. The Gyazo platform breach exposed 23.6 million user records through a server vulnerability. The Pakistan-aligned Transparent Tribe (APT36) deployed novel Rust-based backdoors using private GitHub repositories for command-and-control infrastructure targeting government and defense entities in India and Afghanistan. A malware campaign leverages SEO-optimized GitHub repositories impersonating legitimate software firms to distribute the Rapuncel infostealer. Source: Gyazo server flaw exploited to steal 23.6 million user records, Transparent Tribe Deploys New Rust Backdoor Using Private GitHub Repositories for C2, Fake LastPass Authenticator GitHub repos push new Rapuncel infostealer

AI development tooling introduces new attack surfaces. The Plugin4Shell vulnerability affects four widely used AI coding agents, allowing repository owners to swap pinned plugin code for malicious versions even when agents lock plugins to specific reviewed versions. An abandoned CDN domain re-registered in July 2025 continues to be called by thousands of websites, code repositories, and documentation pages with hard-coded references. Source: Plugin4Shell Lets Repository Owners Swap Pinned Plugin Code Across Four AI Coding Agents, An Abandoned CDN Domain Was Re-Registered. Thousands of Sites Still Call It.

Enterprise governance controls are evolving to address persistent access and data sharing risks. Microsoft 365 access reviews enable centralized access governance and owner-driven reviews to identify and remove unnecessary access. Microsoft Teams will allow administrators to customize blocked file extension lists to meet organizational security requirements. Google Workspace security control prioritization guidance helps lean security teams focus resources on high-value controls. Source: Secure enterprise sharing with access reviews for Microsoft 365, Microsoft Teams will let admins block custom file extensions, Webinar: Which Google Workspace security controls actually matter?
