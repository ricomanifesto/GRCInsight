Patch management itself has emerged as an operational risk vector. Microsoft's September 2026 security updates are confirmed to cause Remote Desktop Services failures on Windows Server [Microsoft: September updates cause RDS failures on Windows Server](https://www.bleepingcomputer.com/news/microsoft/microsoft-september-updates-cause-rds-failures-on-windows-server/) and USB audio device failures on Windows PCs [Microsoft: September updates break audio on some Windows PCs](https://www.bleepingcomputer.com/news/microsoft/microsoft-september-updates-break-audio-on-some-windows-pcs/), creating tension between vulnerability remediation and business continuity.

Identity-focused attacks are evolving beyond credential theft toward authentication protocol abuse. Threat actors are leveraging passkey-themed social engineering and third-party email infrastructure to hijack Microsoft cloud accounts [Attackers Use Passkey Phishing to Hijack Microsoft Cloud Accounts and Exfiltrate Data](https://thehackernews.com/2026/09/attackers-use-passkey-phishing-to.html), while a malicious cross-store Twitch browser extension leaked OAuth tokens from nearly 31,000 users to a Russian commercial bot service [Malicious Twitch Browser Extension Leaks OAuth Tokens From Nearly 31,000 Users](https://thehackernews.com/2026/09/malicious-twitch-browser-extension.html).
