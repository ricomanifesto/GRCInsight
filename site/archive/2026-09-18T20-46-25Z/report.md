Three maximum-severity vulnerabilities disclosed this month demand immediate attention from risk and infrastructure teams. A CVSS 10.0 privilege-escalation flaw in Azure AI Foundry (CVE-2026-85889), a critical Docker Sandboxes container escape on macOS (CVE-2026-77179), and a heap-overflow remote-code-execution vulnerability in the Unbound DNSSEC validator (CVE-2026-81642) each allow unauthenticated attackers to compromise core platform components [Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation](https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html) [Critical Docker Sandboxes Flaw Lets Malicious Guest Code Read and Modify macOS Host Files](https://thehackernews.com/2026/09/critical-docker-sandboxes-flaw-lets.html) [Critical Unbound DNSSEC Validator Flaw Could Allow RCE via a Malicious DNS Zone](https://thehackernews.com/2026/09/critical-unbound-dnssec-validator-flaw.html).

Supply-chain integrity risks are escalating across both traditional and AI-augmented development pipelines. The re-registration of an abandoned CDN domain now serving thousands of hard-coded references demonstrates how legacy asset inventory gaps create persistent attack surface [An Abandoned CDN Domain Was Re-Registered. Thousands of Sites Still Call It.](https://thehackernews.com/2026/09/an-abandoned-cdn-domain-was-re.html). Identity and access governance gaps remain a primary driver of data exposure. The Gyazo breach of 23.6 million user records originated from an unpatched server vulnerability, while SEO-poisoned GitHub repositories impersonating LastPass deliver a novel infostealer, highlighting the convergence of credential theft and software-supply-chain abuse [Gyazo server flaw exploited to steal 23.6 million user records](https://www.bleepingcomputer.com/news/security/gyazo-server-flaw-exploited-to-steal-236-million-user-records/) [Fake LastPass Authenticator GitHub repos push new Rapuncel infostealer](https://www.bleepingcomputer.com/news/security/fake-lastpass-authenticator-github-repos-push-new-rapuncel-infostealer/). Microsoft 365 and Teams are introducing new access-review and file-extension-blocking capabilities to mitigate oversharing and malware delivery risks [Secure enterprise sharing with access reviews for Microsoft 365](https://www.bleepingcomputer.com/news/security/secure-enterprise-sharing-with-access-reviews-for-microsoft-365/) [Microsoft Teams will let admins block custom file extensions](https://www.bleepingcomputer.com/news/security/microsoft-teams-will-let-admins-block-custom-file-extensions/).

Nation-state activity continues to target government and defense sectors with custom tooling. Transparent Tribe (APT36) has deployed previously undocumented Rust-based backdoors—RUSTYSHADE, RUSTYMOVE, PSNATCH, and BASHNATCH—leveraging private GitHub repositories for command and control, signaling increased sophistication in malware development and infrastructure management [Transparent Tribe Deploys New Rust Backdoor Using Private GitHub Repositories for C2](https://thehackernews.com/2026/09/transparent-tribe-deploys-new-rust.html).
