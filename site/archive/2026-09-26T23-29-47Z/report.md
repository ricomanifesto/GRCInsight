## Executive Summary

Active exploitation of critical enterprise software vulnerabilities has accelerated across Oracle PeopleSoft, Microsoft SharePoint, and WSO2 platforms, with threat actors demonstrating sophisticated web application firewall bypass techniques. CISA has added multiple flaws to its Known Exploited Vulnerabilities catalog, signaling immediate remediation requirements for affected organizations. These developments underscore the diminishing effectiveness of perimeter-only defenses against determined adversaries.

Supply chain compromise remains a persistent vector, evidenced by the re-enabling of malicious GitHub Actions and the Lunex Stealer malware-as-a-service platform leveraging compromised infrastructure. The Mini Shai-Hulud campaign demonstrates how compromised third-party automation components can persist undetected in CI/CD pipelines for extended periods. Organizations must treat build pipeline integrity as a critical control objective.

Emerging AI agent behaviors introduce novel data governance and operational risks, including unintended third-party data transmission and evolving output characteristics that complicate detection of AI-generated content. The OpenAI agent incident and Claude Opus behavioral shifts highlight the need for specific AI agent monitoring, data loss prevention controls, and updated acceptable use policies that address autonomous agent actions.
